# ◇ MONOLITH — Algo Trading Platform

## Что это?

**MONOLITH** — алгоритмическая торговая платформа для Московской биржи (MOEX). Мультиагентная система: QUIK/API-брокеры, ML-inference с drift-мониторингом, бэктестинг, paper/live режимы, Telegram-алерты.

> Это **algo trading platform**, не лицензированный хэдж-фонд. Папка `hedge_fund/` — историческое имя пакета.

## Возможности

- 🤖 **Мультиагентная архитектура** — оркестратор, скальпинг, дейтрейдинг, долгосрочные стратегии, хеджирование, риск-менеджмент
- 📊 **Технический и фундаментальный анализ** — RSI, MACD, Bollinger Bands, объёмы, P/E, дивиденды
- 🧠 **Машинное обучение** — предсказание направления движения, детекция аномалий
- 💬 **Локальные LLM (Ollama)** — анализ новостей, генерация торговых идей без отправки данных в облако
- 🛡️ **Многоуровневая защита** — дневной лимит убытков, стоп-лосс, корреляционный мониторинг, PIN-блокировка
- 📱 **Telegram-бот** — статусы, отчёты, команды управления, голосовые оповещения
- 📈 **Бэктестинг** — проверка стратегий на исторических данных с оптимизацией параметров
- 🏗️ **Paper Trading** — режим симуляции без реальных денег
- 🔍 **Мониторинг** — метрики, health-check, алерты, дашборд, ML drift detection
- 🐳 **Docker** — контейнерный деплой, `.env` для секретов
- 🔌 **Live smoke tests** — проверка QUIK/Tinkoff без выставления ордеров

## Установка шаг за шагом

### 1. Скачайте и установите Python

Скачайте Python 3.11+ с [python.org](https://www.python.org/downloads/).  
При установке обязательно отметьте **"Add Python to PATH"**.

### 2. Скачайте и установите Ollama

Скачайте с [ollama.com](https://ollama.com/) и установите.

### 3. Откройте командную строку

Нажмите `Win + R`, введите `cmd`, нажмите Enter.

### 4. Установите зависимости

```bash
cd путь\к\папке\groove-trainer
pip install -r hedge_fund/requirements.txt
```

### 5. Скачайте модель LLM

```bash
ollama pull llama3.1
```

### 6. Запустите систему

```bash
python -m hedge_fund.main
```

## Первый запуск

При первом запуске откроется **мастер настройки** (Setup Wizard):

1. **Подключение к QUIK** — укажите путь к терминалу и проверьте связь
2. **Telegram** — введите токен бота и ID чата
3. **Профиль риска** — выберите один из трёх (Консервативный / Умеренный / Агрессивный)
4. **Инструменты** — выберите тикеры для торговли (по умолчанию: SBER, GAZP, LKOH, YDEX, VTBR)
5. **Режим** — Paper Trading (рекомендуется на старте) или Live

## Настройка QUIK

Для связи с терминалом QUIK необходимо загрузить LUA-скрипт:

1. Откройте QUIK → Сервисы → Lua-скрипты
2. Нажмите «Добавить» и выберите файл `hedge_fund/quik/lua/main.lua`
3. Нажмите «Запустить»
4. В логе QUIK должно появиться: `[Monolith] Connector started`

Скрипт создаёт локальный сервер для обмена данными между QUIK и Python-системой.

## Настройка Telegram-бота

1. Откройте Telegram, найдите **@BotFather**
2. Отправьте `/newbot`, придумайте имя
3. Скопируйте полученный **токен** (формат: `123456789:ABCdefGHIjklMNO...`)
4. Напишите своему боту `/start`
5. Узнайте свой Chat ID: отправьте боту сообщение, откройте `https://api.telegram.org/bot<TOKEN>/getUpdates`
6. Введите токен и Chat ID в мастере настройки (или в `config/settings.yaml`)

## ML-модели

1. Скачайте исторические данные и обучите модели:
   ```bash
   python -m hedge_fund.ml.train_pipeline
   ```
2. Модели сохраняются в `hedge_fund/ml/models/` (scalping_latest.pkl, swing_latest.pkl)
3. QuantAgent автоматически использует их для inference при наличии моделей
4. Без моделей QuantAgent работает через stat arb и anomaly detection
5. **Автопереобучение**: `MLRetrainScheduler` в runtime (см. `ml.auto_retrain_enabled`)
6. **Drift-мониторинг**: PSI + z-score при каждом inference
7. Деплой: см. [DEPLOYMENT.md](../DEPLOYMENT.md)

## FAQ

### ❓ Я потеряю деньги?

Любая торговля на бирже связана с риском. Система имеет многоуровневую защиту (стоп-лоссы, дневные лимиты, аварийная остановка), но гарантий прибыли нет. Начните с Paper Trading.

### ❓ Как остановить систему?

- В Telegram: отправьте команду `/stop`
- В терминале: нажмите `Ctrl+C`
- В desktop-дашборде: кнопка **⛔ СТОП**
- Автоматически: при превышении дневного лимита убытков (DailyLossLock)

### ❓ Что делать если QUIK отключился?

Система автоматически пытается переподключиться (до 5 раз с интервалом 10 секунд). Если связь не восстановлена — все позиции замораживаются, новые ордера не выставляются, в Telegram приходит уведомление.

### ❓ Сколько нужно начального капитала?

Минимум 100 000 ₽ для адекватной диверсификации. Рекомендуется от 500 000 ₽.

### ❓ Система работает ночью?

Нет, система активна только в часы работы Московской биржи (10:00–18:45 основная сессия, 19:00–23:50 вечерняя). В нерабочее время выполняется анализ и подготовка к следующему дню.

### ❓ Можно ли торговать несколькими счетами?

Да, модуль `quik/multi_account.py` поддерживает мультисчета с раздельным риск-менеджментом.

### ❓ Нужен ли GPU для ML?

Нет, модели достаточно лёгкие для CPU. Ollama тоже работает на CPU, хотя с GPU будет быстрее.

### ❓ Как добавить свою стратегию?

Создайте класс, наследующий `BaseStrategy` в папке `strategies/`. Реализуйте методы `generate_signal()` и `should_exit()`. Зарегистрируйте в оркестраторе.

### ❓ Данные хранятся в облаке?

Нет. Все данные хранятся локально (SQLite + файлы). LLM работает через Ollama локально. Ничего не отправляется на внешние серверы.

### ❓ Как обновить систему?

```bash
cd groove-trainer
git pull
pip install -r hedge_fund/requirements.txt --upgrade
```

## Технические детали

### Архитектура

Система построена на **мультиагентной архитектуре** с централизованной шиной событий (Event Bus). Каждый агент — это асинхронный воркер, который подписывается на определённые типы событий и публикует свои сигналы.

```
QUIK (LUA) ←→ Connector ←→ Event Bus ←→ Agents ←→ Risk Manager ←→ Order Manager
                                ↕
                          ML / Ollama
                                ↕
                        Telegram / Dashboard
```

### Агенты

| Агент | Роль |
|-------|------|
| Orchestrator | Координация, приоритезация сигналов |
| Scalping Agent | Сделки на секунды-минуты |
| Day Trading Agent | Внутридневные сделки |
| Long Term Agent | Позиции на дни-недели |
| News Agent | Анализ новостей через LLM |
| Risk Agent | Контроль лимитов в реальном времени |
| Quant Agent | Количественный анализ, ML-сигналы |
| Hedging Agent | Хеджирование портфеля |
| SRE Agent | Мониторинг здоровья системы |

### ML Pipeline

1. Загрузка OHLCV с MOEX (`data/moex_loader.py`)
2. Feature Engineering: 50+ признаков (returns, RSI, MACD, Bollinger, volume profile)
3. Обучение модели (gradient boosting / neural net)
4. Инференс в реальном времени с мониторингом latency
5. Детекция аномалий для фильтрации ложных сигналов
